# Hive 0.1.2

Per-stack sync controls, host reveal toggles, stronger review sessions, and UI polish.

## Sync controls

- Stacks kept only on this phone are now marked as unsynced with a slashed cloud icon whenever you are signed in.
- Use Sync or Unsync on a stack's details page to manage individual stacks; unsyncing removes that stack from the server while keeping your local copy.
- Use Sync all or Unsync all in Settings to update every stack at once.
- The Sync button in Account now retries the server connection when offline and animates while syncing.

## Review sessions

- You can now abandon an ongoing review instead of only pausing it, and step back to check past answers with Previous.
- Questions now count as answered as soon as you submit an answer, without waiting to advance.
- Home replaces My Stacks with a swipeable gallery of up to 5 ongoing reviews (with indicator dots); starting a sixth automatically finishes the oldest one.
- Stack Details shows Continue review when that stack already has an unfinished review.
- Replaying a review from History uses the latest version of its stack, or lets you restore the stack if it was deleted.

## Live sessions and layout

- Hosts can now turn showing answers and explanations on or off in Host Setup and Edit Session, and Asynchronous sessions reveal answers immediately after submitting when enabled.
- Answering actions (Previous, Skip, Confirm, Next, Finish) are now pinned to the bottom bar in Review and Live Quiz.
- Top bar headers now use normal capitalization instead of all capitals.

## Fixes

- Activity streaks and average scores now count only finished sessions, guest online sessions are saved in local history, and session dates reflect when the session started.
- Hardened account deletion on the server so deleted sign-ins close open hosted sessions immediately, revoke participant tokens, and block token reuse.

## Install

Download `hive-0.1.2.apk` below and open it on an Android 8.0 or newer phone. It updates an installed Hive 0.1.1 while keeping your local data. Allow installing from this source when Android asks.
