# Hive 0.1.1

Account display names that sync across phones, and sentence-case buttons.

## Display names

- Signed-in accounts now keep a display name on the server, starting from your sign-in name.
- Use Edit display name in Account to change it. Other players see the new name in online sessions, and your other phones pick it up on the next sync.
- Changes made while offline wait and sync when you are back online.
- Signed out, Edit name stays for your guest name on this phone.

## Buttons

- Buttons and text actions now use normal sentence case instead of all capitals, keeping the condensed bold font at a slightly larger size.
- Headings, section captions, and badges stay in capitals.

## Install

Download `hive-0.1.1.apk` below and open it on an Android 8.0 or newer phone. It updates an installed Hive 0.1.0 while keeping your local data. Allow installing from this source when Android asks.
